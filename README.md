# 個人用Webアプリ集（端末保存版）

ブラウザで開いて使う単一ファイルのWebアプリです。入力したデータは、開いた端末のブラウザ内（localStorage）にのみ保存され、このリポジトリには含まれません。

## アプリ一覧

- [収支管理](https://konpota777.github.io/shushi-app/)：収入・支出・収支の管理（バイト合計、年末計上リスト、無駄遣い候補）
- [旅行計画](https://konpota777.github.io/shushi-app/travel/)：旅行ごとの行程表、予算と費用目安、持ち物チェックリスト
- [買い物比較](https://konpota777.github.io/shushi-app/shopping/)：ショップごとの価格・送料・評価を登録して総額の最安とおすすめを比較

## 共通の使い方

1. アプリのページを開く
2. データはその端末のブラウザに保存されます。たまに各アプリの「データを書き出す（JSON）」でバックアップしてください
3. iPhoneの場合は Safari の共有メニューから「ホーム画面に追加」するとアプリのように使えます
