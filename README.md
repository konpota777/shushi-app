# 収支管理アプリ（端末保存版）

日々の収入・支出・収支を記録する単一ファイルのWebアプリです。
入力したデータは、開いた端末のブラウザ内（localStorage）にのみ保存され、このリポジトリには含まれません。

- 月別／年間の収支まとめ（現金と投資分の内訳）
- バイト収入の合計表示
- 年末計上リスト
- 無駄遣い候補の表示
- データのJSON書き出し・読み込み（バックアップ／引っ越し用）

## 使い方

1. 公開ページ（GitHub Pages）を開く
2. 手元のデータファイル（JSON）をアプリ内の「JSONを読み込む」から読み込む
3. iPhoneの場合は Safari の共有メニューから「ホーム画面に追加」するとアプリのように使えます
